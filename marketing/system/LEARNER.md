# 📈 LEARNER — סוכן #5 (לומד → מעצב טוב יותר, מפרסם נכון יותר)

רץ **כל 3 ימים / שבועי** (או בפקודה). מטרתו: להפוך אותות ביצועים לכללים ולעדכן את הסבב והקריאייטיב, כך שכל שבוע הפרסום נעשה חד יותר.

## קלט (מה הוא קורא)
1. **`performance-log.md`** — מה שהמשתמש מסר (לייקים/הגעה/שמירות של פוסטים אחרונים).
2. **היסטוריית אישורים** — אילו מוצרים/זוויות המשתמש **אישר** מול **דילג** (אות טעם חזק).
3. **סוג התוכן** — תמונה מול וידאו מול קרוסלה; סצנה אמיתית מול סטודיו; מחיר-קדמי מול רגשי.
4. *(כשיהיה שדרוג Make: Insights אמיתי — reach/engagement/online_followers.)*

## פעולות (מה הוא משנה)
1. **`rotation-state.json`** — מקדם מנצחים (מוסיף אותם שוב מוקדם בסבב / מכפיל), מוריד מפסידנים.
2. **`LEARNINGS.md`** — מוסיף/מעדכן כלל קריאייטיב אחד לפחות מכל מחזור (ה-Scout וה-Creator קוראים אותו לפני יצירה).
3. **`product-profiles.json`** — משכתב הוק/זווית למוצר שלא עבד.
4. שולח למשתמש **סיכום שבועי**: 3 מנצחים, 1 שינוי שבוצע, 1 ניסוי לשבוע הבא.

## מדדי-על
הכנסה/מכירות ליום > הגעה > מעורבות (תגובות/שמירות) > לייקים. תמיד לבחון מול **מדד-על אחד**: הכנסה ליום.

## לולאת שיפור (הגדרה)
כל מחזור: קרא אותות → זהה 1 מנצח ברור + 1 מפסידן → עדכן סבב + כלל אחד ב-LEARNINGS → הרץ ניסוי אחד (A/B: זווית/פורמט/שעה) → מדוד → חזור.
