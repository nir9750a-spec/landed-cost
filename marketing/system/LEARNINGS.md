## 🧠 מדדי ויראליות (Higgsfield Virality Predictor — נמדד 2026-08-12)
- רילס מנגל: **הוק (3ש' ראשונות)=38/100**, **החזקה=99/100**, כללי=55, שיא עניין=שנייה 5.
- **מסקנה:** ההחזקה מצוינת — הבעיה היא **הפתיחה**. המוח "משועמם" (Default Mode גבוה) ב-0–3ש' ומתעורר רק כשהטקסט/מחיר מתגלים (ש' 5).
- **פעולות מוכחות להוק:** (1) מוזיקה טרנדית = המנוף הכי גדול. (2) פתיחה נועזת בפריים 0 — כותרת/מחיר גדולים מיד, או תנועה/אקשן אמיתי (אש/אנשים), לא מוצר סטטי. (3) לופ חלק, וידאו אמיתי > סטילס.
- מיקרו-תזמון (fade 0.6→0.3ש') **לא** הזיז את הציון (המודל דוגם 1 פריים/שנייה) — צריך שינוי **תוכן** בפתיחה, לא תזמון.
- הכלי: `virality_predictor` (חינם בתוכנית). ייבוא וידאו ל-Higgsfield דרך **jsDelivr** (`cdn.jsdelivr.net/gh/<user>/<repo>@<sha>/<path>`) כי GitHub raw מחזיר octet-stream ש-Higgsfield דוחה.
