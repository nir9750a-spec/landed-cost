## למה התחלנו מחדש

הפרויקט הקודם ערבב שני עסקים ואפליקציה שלמה באותו ריפו. 12 ענפים, עשרות מסמכים,
וחלקם סתרו זה את זה. אי אפשר היה למצוא כלום, והמודעות יצאו רע.

**מה שנשמר:** הקטלוג, המנוע המתוקן, ו-8 המודעות שעבדו.
**מה שנזרק:** כל השאר.

הענפים הישנים **לא נמחקו** — הם קיימים ב-GitHub אם יתברר שחסר משהו.
