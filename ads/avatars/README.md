# 🧑 אווטארים — תמונות הרפרנס של ניר

כאן שמים את התמונות שמהן ה-AI לומד איך ניר נראה. ככל שיש יותר זוויות — הדמיון טוב יותר
והמודעות פחות נראות משוכפלות.

## איך מוסיפים

1. **זרוק קבצים לתיקייה הזאת** (`ads/avatars/`) — jpg/png, רצוי 1024px ומעלה.
   שם הקובץ הופך ל-id, אז תן שמות ברורים: `nir-half-body.jpg`, `nir-seated-side.jpg`.
2. הרץ:
   ```
   cd ads && python avatars.py scan
   ```
   כל תמונה חדשה נרשמת ב-`registry.json` כ-⬆️ (ממתינה להעלאה).
3. בשיחה עם Claude תגיד **"תעלה את האווטארים החדשים"** — הוא מעלה ל-Higgsfield
   וממלא `media_id` לכל אחת. רק אחרי זה אפשר להשתמש בהן בייצור.

## איזה תמונות הכי עוזרות

| סוג | תיוג מומלץ | למה |
|---|---|---|
| פנים מקרוב, אור יום, בלי משקפי שמש | `portrait` | עוגן הדמיון — הכי חשוב |
| חצי גוף, עומד | `half-body` | לסצנות עמידה ליד המוצר |
| גוף מלא / יושב | `seated`, `full-body` | לכיסאות ושולחנות |
| פרופיל / שלושת-רבעי | `side` | מונע שכל המודעות באותה זווית |
| בשטח, בגדי אאוטדור | `outdoor` | הכי קרוב לאווירת המותג |

3–6 תמונות מגוונות זה המתוק. יותר מזה לא באמת משפר.

## חוקים

- **רק תמונות של ניר עצמו.** לא לשים פנים של אנשים אחרים.
- לא תמונות מטושטשות/כהות — הן פוגעות בדמיון יותר משהן עוזרות.
- הקבצים כאן **כן** נכנסים לגיט (הם לא סוד) — אבל `registry.json` הוא מקור האמת.
