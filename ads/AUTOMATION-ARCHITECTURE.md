# מעטפת פרסום אוטומטית ל-4Elements — הדרך הנכונה
*מחקר + תוכנית · 19.7.2026*

## החזון
אתה אומר מוצר → אני מייצר מודעה/ריל + כיתוב → **מתפרסם לאינסטגרם אוטומטית**. + ניהול, מדידה, לוח.

## למה שליטה בדפדפן לא עובדת (ולא תעבוד)
אינסטגרם **חוסמת בכוונה** העלאת קבצים ואוטומציה מהדפדפן, ועריכת לינק-בביו + מוזיקה זמינות רק באפליקציית הנייד. זו מגבלת אבטחה של Meta — לא באג. **הדרך הרשמית היחידה לפרסום אוטומטי = Instagram Graph API.**

## שתי דרכים אמיתיות

### דרך A — Metricool (מומלץ להתחיל · בלי קוד · עובד השבוע)
כלי ניהול שמחובר ל-API הרשמי. תוכנית **חינם**: 50 פוסטים/חודש, IG+FB, פרסום אוטומטי מתוזמן.
- זרימה: אני מייצר ריל+כיתוב → נטען למתכנן Metricool → מתפרסם לבד בזמן שנקבע.
- **מוזיקה:** Metricool קיבל גישה לספריית אודיו מצומצמת (מורשית לצד-שלישי) בתוך המתכנן.
- יתרון: מהיר, חינם, אמין, כולל אנליטיקות. אוטומציה מלאה (טעינה אוטומטית) — בתוכניות בתשלום/API.

### דרך B — Instagram Graph API (אוטומציה מלאה · "Claude מפרסם לבד")
ה-API הרשמי של Meta לפרסום תוכן.
- דרוש: חשבון IG עסקי ✅ + עמוד FB ✅ + **אפליקציית Meta Developer** + **טוקן גישה** (הרשאות `instagram_basic` + `instagram_content_publish`) + אישור App Review לפרודקשן.
- איך זה עובד: המדיה מתארחת בכתובת ציבורית (URL) → יוצרים "container" (media_type=REELS, video_url) → ממתינים שהעיבוד יסתיים → publish. MP4/H.264, עד 90 שניות, עד 25 פוסטים/24ש'.
- אני יכול **לכתוב את הסקריפט** שעושה את זה מקצה-לקצה (כולל תזמון/cron).
- **הטוקן + האפליקציה** — מנהל האתר (שכבר עוזר עם הפיקסל) יכול להקים; זה אותו עולם.

## מגבלת מוזיקה (חשוב — לכל דרך אוטומטית)
Meta **לא מאפשרת** מוזיקה מהספרייה המובנית (טרנדים/מורשית) בפרסום אוטומטי — רק **אודיו מורשה/רויאלטי-פרי** או אודיו מוטמע בסרטון. סרטון עם שיר טרנדי ספציפי — חייב להתפרסם ידנית מהאפליקציה.
**הפתרון שלנו:** אני מטמיע מוזיקה רויאלטי-פרי בריל עצמו (ffmpeg) → נשמע מצוין, מתפרסם אוטומטית, בלי בעיות זכויות.

## התוכנית המומלצת
1. **עכשיו (השבוע):** מחברים את IG+FB ל-**Metricool** (חינם). אני מייצר, טוען, מתזמן → מתפרסם לבד. יוצאים לדרך מיד.
2. **במקביל:** מנהל האתר מקים **אפליקציית Meta + טוקן** → אני בונה **סקריפט Graph API** לפרסום אוטומטי מלא (אתה אומר מוצר → מתפרסם). מוזיקה רויאלטי-פרי מוטמעת.
3. **מדידה:** הפיקסל+קטלוג (שכבר בתהליך אצל המנהל) סוגרים את הלולאה — יודעים מה מוכר.

## מה שכבר מוכן אצלנו
מנוע יצירת מודעות (תמונות+רילים+כיתובים), נכסים אמיתיים, בריפים ל-42 מוצרים, לוגו, מחירים. חסר רק **צינור הפרסום** — וזה מה שבונים כאן.
